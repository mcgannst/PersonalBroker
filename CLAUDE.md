# PersonalBroker

## Branching

- Work directly on the trunk: `claude/finviz-wheel-strategy-screener-x102q2` (the repository's default branch).
- Do not create feature or working branches. If a session is assigned a different branch, commit and push to the trunk instead.
- After changing a skill under `.claude/skills/<name>/`, rebuild `dist/<name>.zip` in the same commit.
