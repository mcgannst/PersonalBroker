# Trader

Workspace for trading tools and notes.

## Options simulation

A separate simulated options account (manual order desk plus strategy plug-ins, the wheel first) runs beside the stock simulation. See `docs/SPEC.md` section 19 and `docs/plans/2026-10-05-options-simulation.md`. Web: the Options page. CLI: `trader options-run new`, `options-check`, `options-refresh`, `options-postclose`, `options-event`.
