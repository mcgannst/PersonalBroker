## Gotchas
- **Heartbeat: `/account` reads `worker_heartbeats` where `process == "options-worker"` (`options_views.WORKER_PROCESS`). T12 must write that exact name.**
- `/strategies` skips a plug-in with no config row yet (the host's `ensure_defaults` must have run).
- Chain-quote cache lives on `app.state.options_chain_cache`, per API process, TTL `options.web_quote_cache_seconds`.
- Questrade failures (`QuestradeApiError`, `QuestradeAuthError`, `httpx.HTTPError`, `TimeoutError`, `OSError`) from the market or broker become 503 on chain, preview and submit; on marks and the benchmark they are swallowed. Any other exception type from T3/T5 would be a 500.
- Marks are computed in the API from `market.quotes`: long option at bid, short at ask, shares at last. Position `delta` is in share equivalents.
- Reads that have no protocol method go straight to the tables: `/prompts?status=all` (`owner_prompts`), leg fills and `/activity` (`opt_fills`, `opt_order_legs`, `opt_lifecycle_events`, `owner_prompts`, `event_log`).
- `event_log` mapping for the activity feed: warning or worse -> `alert`; an info row whose source is `options.broker*` or `options.order*` -> `order`; anything else -> `decision`. Feed `source` is the strategy key for `options.strategy.<key>`, else the part after `options.`. `underlying` and `structure_id` come from the row's `data` when present. **T7/T12/T13 should log with sources of that shape.**
- Ticket validation: 422 for a ticket that cannot form a clear order; leg count, quantity, cover and cash stay the collateral engine's verdict (the order comes back `rejected`).
- Manual orders carry `reason="manual"`, `submitted_by="web:<username>"`.
