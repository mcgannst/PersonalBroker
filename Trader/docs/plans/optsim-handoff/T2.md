## Methods on `QuestradeClient` (all on the `market` bucket)
- `async option_chain(symbol_id: int) -> list[QtChainExpiry]`: one `GET symbols/{id}/options`; expiries ascending, each the ET date of `expiryDate`.
- `async option_quotes(ids: Sequence[int]) -> list[QtOptionQuote]`: `POST markets/quotes/options` with `{"optionIds":[...]}`, 100 ids per request (`OPTION_IDS_PER_CALL`, an R11 assumption). Empty ids make no call.
- `async option_quotes_filter(underlying_id, expiry: date, right, min_strike=None, max_strike=None) -> list[QtOptionQuote]`: one POST with `{"filters":[{...}]}`; `expiryDate` rebuilt as midnight ET with its offset; strike keys left out when None; strikes go on the wire as JSON numbers.
- `async symbol_details(ids: Sequence[int]) -> dict[int, QtSymbolDetails]`: `GET symbols?ids=` in chunks of 100 (**not yet checked live with several ids: T17**); ids Questrade does not return are left out.

## Behaviour
- POST retries match GET: one forced refresh on 401, package 401 (code 1022) raised at once, 429 pauses the bucket, 5xx and transport errors back off, five attempts then `QuestradeApiError`; a 400 is raised without retry.
- **`_get_sent` now delegates to a shared `_request_sent(path, params, category, body)`.** A GET still calls `self._http.get` with the same arguments; all 107 existing Questrade adapter tests pass unchanged. (This is a refactor of the stock data path: the wave checker reviews it.)
- A 0 bid is passed on as `Decimal("0")`, not None (T5's fill model tells `zero_bid` from `one_sided`). Only JSON null or a missing key becomes None.
- `iv_pct` is Questrade's percentage unchanged (T3 divides by 100). `delay` is None when absent.
- `option_chain` raises `ValueError` if an expiry has no `expiryDate`; parse errors are not wrapped in `QuestradeApiError`. A missing `multiplier` defaults to 100.
- `symbol_details` does not fall back id by id on a 400 chunk.
