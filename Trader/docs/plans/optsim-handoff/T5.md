## Fix round (commit 6d4254e; gate 5070 passed, web 861): this section overrides the notes below where they differ
- **`poll` no longer raises for one order's failed fill.** That fill is rolled back, the order stays working, one `event_log` error row is written (source `options.broker`, message `option order fill failed`, data `{order_id, error}`), and every fill that committed is returned. `poll` can still raise if the quote fetch or the working-orders read fails.
- **A buy leg whose ask is 0 or less is no fill** (reason `one_sided`, detail `leg N: the ask is 0`). `zero_bid` now means a bid of 0 or less. `valuation.liquidation_price` gives no mark for a short at an ask of 0 or less (carried at its last mark or cost, `marks_complete` False); `valuation.close_net` returns None when a leg to buy has no positive ask or a leg to sell has no positive bid, so `take_profits` does nothing. A long at a bid of 0 is still marked at 0.
- **A close for more than the structure holds** (or a wrong-direction close, a missing structure, a close leg with no structure named) cancels the order with `invalid_order` and a detail, in `_fill`, before the fill model runs: a poll pass can now move an order to `cancelled` on its own.
- **`walk` and `take_profits`** return `0` / `[]` outside session hours without fetching quotes, and skip an order or structure whose leg quotes are unusable (missing, delayed, halted, stale, one-sided, crossed, zero bid or ask). Both are safe to call at any time.
- New public helper: `fill_model.quote_problem(legs, quotes, now, settings) -> NoFill | None`.

## Behaviour the callers rely on
- `add_structure` and `submit` raise `UnknownUnderlying` when the ticker has no `symbols` row (nothing stored).
- **`poll(now)`** returns `[]` without fetching quotes outside session hours; one `market.quotes` call per pass. An exception inside a fill rolls that fill back and propagates: **the worker must catch it.**
- **`walk(now)`** returns the number of orders that moved (a walk step the collateral engine refuses is skipped).
- **`take_profits(now)` returns the new ORDER ids**: closing limits with reason and `submitted_by` both `take_profit`, carrying the structure's own source. One the collateral engine refuses is not stored.
- **`expire_day_orders(session_date, now)`** also expires day orders of earlier sessions. An order submitted after the close gets the next session's `session_date`.
- A filled open order gets `structure_id` set to the structure it created; the structure's `meta` holds `{"order_id": ...}`.
- `reprice` returns False when the order is not working or the collateral engine refuses the new limit.
- `DbBook.set_entry(structure_id, entry_net, take_profit_net)` is outside the protocol (a roll uses it).
- Cancel reason and actor have no column: `cancel`, `reprice` and a cancel-at-fill write an `event_log` row (source `options.broker`).
- Order reservation is net of the credit: `max(0, rise of the structure's reserve + fees - net x 100 x qty)`, matching T4's `free_cash_after`.
- The fill model reads the contract multiplier from `LegQuote.raw["multiplier"]` (100 when absent); the broker puts it there.
- Valuation with no mark at all: the position is carried at cost and `marks_complete` is False.
- Ledger refs: each leg is `opt_fill:<fill id>`; the single fee row uses the first leg's fill id. A structure is in units of `valuation.structure_units` (gcd of its open position quantities); `opt_structures.qty` is not reduced on a partial close.
