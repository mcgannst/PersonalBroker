## Running a plug-in
- `await host.fire(key, OptionEvent(event_key, session_date, scheduled=...), force=False)` -> `JobOutcome`. Job name `opt_event:<key>:<event>` (`job_name(key, event)`), once per session date. Success detail `{"intents", "submitted", "rejected", "dropped"}`.
- Unknown strategy raises `KeyError`; an event key not matching `KEY_PATTERN` raises `ValueError`.
- A skip (no run, paused, disabled) returns `skipped` with a reason, writes one info event and records no job (the event can still fire later). A raising `on_event` gives a `failed` outcome.
- `panel` / `action` without an options run raise `NoOptionsRun` (a `LookupError`). A raising `on_action` returns `PanelActionResult(False, "The action failed (<Type>)")`.

## Gotchas
- **T12, retry spam:** `due_events` returns every passed, not-yet-succeeded event, so a failing event comes back on every poll and each `fire` writes an error event. **T12 must rate-limit re-firing of failed events**, or the owner gets an alert every poll.
- `due_events` returns `[]` with no run, when paused, or on a non-session day; enabled plug-ins only; ordered by scheduled time, then key.
- **T13:** `deliver_lifecycle` is idempotent through `opt_lifecycle_events.delivered_at`, set under `lock_book`. Do not call it while holding the book lock in another open transaction on the same run. Lifecycle events with no plug-in owner (source `manual` or an unregistered key) are marked delivered without a hook call.
- **T12:** `deliver_fill` has no delivered marker; a raising `on_fill` is logged as an error event and not retried.
- Paused or disabled plug-ins still receive fills, lifecycle events and answers (so their records stay true), but any intents they return are dropped with a warning note.
- **T11, orders:** the host submits with `source=<key>`, `strategy_config_id=<current config id>`, `submitted_by="strategy:<key>"`.
- **T11, closing legs:** close and roll legs are the structure's non-zero positions reversed, order `qty = structure.qty`, `ratio = abs(position qty) // structure.qty`. Roll legs are numbered closing first, then opening.
- **T11, own structures only:** an intent on a structure not among the plug-in's own open structures, or on an order whose source is not the plug-in, is dropped with an error event. `SellShares` also requires `kind == "shares"`.
- **T11, context:** `ctx.params` comes from the stored config. `ctx.session_date` is the event's date in `fire`, otherwise the clock's ET date. `ctx.equity_on(day)` is the last `equity_snapshots` row of the options run on that ET day. `ctx.prompt(key)` returns only the plug-in's own prompts.
- Note data is stored as JSON with `default=str` (Decimals and dates become text). Panel reads record no notes.
- `fire` uses the job runner's default: a crashed event is re-run on the next call, so **plug-ins check `ctx.orders` before re-submitting** (as the toy plug-in does).
- `sync_prompts()` returns opened plus cancelled. `watch_underlyings()` is empty with no run.
- The gate queue is not first-come-first-served; a queued gate call can sit for 30 minutes. Give the gate Bash call a long timeout.
