## Behaviour the callers rely on
- **T13:** `refresh(tickers)` returns `UnderlyingFacts` or an error string per ticker. The string appears only for an unknown symbol or when all four fetches failed; nothing is stored then. Partial failures are logged (`options.facts.source_failed`), not returned. `refresh` is sequential, about 2 s per ticker. A ticker missing from `symbols` is looked up and upserted.
- The service asks `bars` for 260 sessions ending with the last completed session. `sma50_prior` needs 70 bars, `low_52w` needs 252 (bar lows); fewer gives None.
- **T11:** `get(ticker)` returns the newest row by `as_of`, or None if `fetched_at` is older than `options.facts_max_age_hours`.
- **T11:** `sources[field] = (source, fetched_at)` exists for every field of a source that answered, including fields whose value is None. A field absent from `sources` means its source failed. Source names: `questrade`, `finviz`, `candles`.
- A failed source keeps the same day's earlier values (the upsert only writes fields of sources that answered).
- **T11 must apply the owner's security-type override itself** on top of `facts.security_type` (`wheel_tickers.security_type_override` is a plug-in table the core does not read).
- **T9/T11:** `sector` is Questrade's `industrySector` text as it arrives; match the spec's `relaxed_sectors` case-insensitively, with a mapping where needed.
- Fund detection: any non-`Stock` security type, any ticker in the broad-index list, or a `Stock` whose description has one of `etf, etn, fund, ishares, spdr, proshares, direxion, vanguard`. Leveraged/inverse keywords are checked only for funds. The token `short` can flag a short-term treasury fund: the owner override fixes those.
- `sessions_since_52w_low == 0` means the newest completed bar made the low.
