## Gotchas for T11
- **`facts` must not be None.** When `FactsProvider.get` returns None, pass an empty `UnderlyingFacts(symbol_id, as_of, ticker)`; the tests then report `MISSING_DATA`.
- Apply the owner's security-type override with `dataclasses.replace(facts, security_type=...)` before calling.
- **`PutPosition.premium` is the open put's own sale price.** On a roll keep the running sum in `total_put_premium` and set `premium` to the new put's price, or the profit target is wrong after a roll.
- `evaluate.put` wants the open put's own row as `quote` (only `ask` is read) and the next monthly expiry's puts as `next_monthly_puts`. `ROLL_PUT` carries `candidate` and `detail["net_credit"]`.
- **Fresh-cash before every call:** `evaluate.shares` returns `RUN_FRESH_CASH_TEST` when the answer is None or 30 days old, `SELL_SHARES` when it is False. To force a retest before each new call, clear `fresh_cash_answer` when a call closes or expires.
- `net_cost` is supplied by the caller: `calc.net_cost(..., include_call_premium=cfg.cc_include_call_premium_in_net_cost)`.
- Entry check: `ScreenResult.entry_allowed` and `stops.can_open(...) is None`.
- `AlertSnapshot.quarter_end` is set by the caller; for `BENCHMARK_REVIEW_DUE` alone pass a state `NONE` snapshot. Alerts fire on the day a condition starts. `EARNINGS_MOVED` and `THESIS_FLAG` need a previous snapshot (keep it in the strategy state).
- Low-delta calls often fail liquidity (a 5-cent spread on a 0.30 bid is over the 15% limit), so `HOLD_UNCOVERED` will be common.
